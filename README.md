
# 🎓 InsideUGAL

> Platforma internă de colaborare și coordonare pentru studenții și coordonatorii Universității "Dunărea de Jos" din Galați.

---

## 📌 Despre Proiect

**InsideUGAL** este o platformă digitală creată pentru a facilita comunicarea și colaborarea între studenți și coordonatori în cadrul Universității "Dunărea de Jos" din Galați (UGAL).

Proiectul centralizează activitățile academice, simplifică fluxul de lucru și creează un spațiu comun unde informațiile ajung rapid la toți cei implicați — potențat de **Inteligență Artificială** (LLM, RAG, Fine-tuning).

---

## 🎯 Scopul Proiectului

- Îmbunătățirea comunicării dintre studenți și coordonatori
- Centralizarea resurselor și activităților universitare
- Simplificarea coordonării proiectelor și sarcinilor
- Crearea unei comunități digitale pentru membrii UGAL
- Integrarea AI pentru personalizarea experienței academice

---

## ⚙️ Funcționalități

### 👨‍🎓 Pentru Studenți
- 📋 Orar personalizat
- 📊 Note și examene în timp real
- 💬 Chat cu colegi și coordonatori
- 📢 Anunțuri și notificări
- 🤖 Asistent AI

### 👨‍🏫 Pentru Coordonatori
- 📁 Gestionare cursuri și materiale
- 👥 Catalog studenți și prezențe
- 📊 Analiză AI
- 📢 Sistem de anunțuri

---

## 🛠️ Tehnologii Folosite

- **Frontend:** React, TailwindCSS
- **Backend:** Node.js, Express, Socket.io
- **AI:** Python, FastAPI, LangChain, GPT-4, ChromaDB
- **Baze de date:** PostgreSQL, Redis
- **DevOps:** Git, GitHub, Docker

---

## 🚀 Cum rulezi proiectul local

```bash
git clone https://github.com/alexurrc18/InsideUGAL
cd InsideUGAL
npm install
npm start
```
